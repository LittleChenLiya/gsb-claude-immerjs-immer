# RFC 6902 conversion for Immer patches

`toJsonPatch(base, patches)` (exported from `immer`, implemented in
`src/utils/rfc6902.ts`) explicitly converts a list of Immer patches into an
[RFC 6902](https://datatracker.ietf.org/doc/html/rfc6902) JSON Patch
operation group with [RFC 6901](https://datatracker.ietf.org/doc/html/rfc6901)
JSON Pointers.

```ts
import {produceWithPatches, toJsonPatch} from "immer"

const [result, patches] = produceWithPatches(base, recipe)
const operations = toJsonPatch(base, patches) // RFC 6902 operations
```

## How it works

- The converter walks the Immer patches in order and maintains a private
  *candidate document*: a deep clone of `base` to which every emitted
  operation is applied immediately. Each step is therefore validated against
  the state produced by the previous steps, never against the stale base.
- Path segments are resolved against the candidate document, so numeric
  segments are **not** blindly treated as array indices: inside an array `0`
  is an index, inside a plain object `"0"` is an ordinary key.
- Keys are escaped per RFC 6901 (`~` -> `~0`, `/` -> `~1`), so the key
  `a/b` becomes the pointer segment `a~1b`.
- Array appends (Immer `add` at the index equal to the array length, or the
  `-` segment) are emitted at the legal RFC 6901 append position `-`.
- A root replacement (empty Immer path) is emitted with the empty pointer
  `""`.
- Conversion is **atomic**: either every patch converts and the full
  operation group is returned, or a `JsonPatchConversionError` is thrown and
  no (partial) group is produced. Neither `base` nor `patches` is mutated,
  and the returned operations share no references with the inputs.

## Supported scope

Supported:

- Base states and patch values composed of JSON values only: `null`,
  booleans, finite numbers, strings, plain arrays and plain objects.
- The Immer operations `add`, `remove` and `replace`.

Explicitly rejected (with `JsonPatchConversionError`):

- `Map` and `Set` — anywhere in the base state or in patch values.
- Non-JSON values: `undefined`, functions, symbols, bigints, non-finite
  numbers (`NaN`, `Infinity`), class instances (`Date`, `RegExp`, ...) and
  cyclic structures.
- Any other patch operation (e.g. `move`, `copy`, `test`).
- Patches whose paths do not resolve against the candidate document
  (missing keys, out-of-range indices), and removal of the document root.

## Tests

Run the targeted suite with:

```sh
yarn test:rfc6902
# or: npx vitest run __tests__/rfc6902.js
```

The suite verifies pointer generation (numeric keys vs. indices, escaping,
root replacement, array append positions), explicit rejection of
Map/Set/non-JSON values, atomic all-or-nothing failure, input immutability,
and — using an independent in-test RFC 6902 executor — that applying the
converted operations to the base state yields exactly the Immer result.
